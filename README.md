# Global-Superstore-Sales-Analysis
Interactive Power BI dashboard analyzing sales performance, profitability, customer behavior, and regional trends using the Global Superstore dataset. 

## Project Overview


As part of my Data Analytics Internship at Syntecx Hub, I developed an interactive Sales Performance Dashboard using the Global Superstore dataset.


The objective of this project was to transform raw sales data into actionable business insights that can support strategic decision-making.


Rather than focusing only on visualization, I concentrated on identifying sales trends, customer behavior, product profitability, shipping performance, and regional sales patterns.


## Business Questions Answered
- Which regions generated the highest sales?
- Which product categories contributed most to revenue?
- What was the overall profit margin?
- Which products were the most profitable?
- Which products consistently underperformed?
- Which shipping mode generated the highest sales?
- How did sales change across different years?

## Key Insights
- Technology products generated the highest revenue contribution.
- Standard Class shipping accounted for the majority of sales.
- A small group of products contributed significantly to overall revenue.
- Several products generated sales but delivered weak profitability, highlighting opportunities for portfolio optimization.
- Sales performance varied considerably across regions and countries.
